# 页面状态机与操作边界

每轮执行顺序固定为：`截图 → OCR/模板识别 → 模态框路由 → 普通页面路由 → OCR 回读校验`。

模态框优先级最高；出现弹窗时，不执行底层页面动作。

## 普通页面

| 页面标识 | 识别依据 | 允许操作 | 退出条件 | 禁止操作 |
|---|---|---|---|---|
| `auth_page` | 登录、注册、手机号等文字 | 等待人工登录 | 登录后进入导航页 | 自动登录、注册、验证码操作 |
| `navigation` | 顶部搬砖入口 | 点击“搬砖” | 进入搬砖页 | 在首页直接挂单 |
| `move_page` | 搬砖余额或开始搬砖按钮 | 读取余额、跟踪挂单、开始挂单 | 进入表单、订单页或等待余额 | 余额不足最小限额时新增挂单 |
| `withdraw_form` | 金额、限额、确认变现表单元素 | 填金额、限额、选收款卡、提交 | 二次确认、支付密码、返回搬砖页 | 任一字段 OCR 未回读时提交 |
| `withdraw_unavailable` | 余额不足 10 且没有表单 | 点击左上角返回 | 回到搬砖页 | 尝试填写不存在的输入框 |
| `orders_list` | 订单标签和状态标签 | 查看订单、定期下拉刷新 | 进入详情或识别空订单 | 点击不确定订单行 |
| `orders_empty` | 订单页空状态 | 返回搬砖页 | 回到搬砖页 | 继续停留并重复刷新 |
| `order_detail` | 搬砖详情、出售详情、订单详情 | 点击左上角返回 | 返回订单列表或搬砖页 | 点击取消变现或资金确认 |
| `waiting_transfer` | 待付款、等待买家转账 | 发送一次待付款通知、等待状态变化 | 进入详情或订单列表 | 确认到账、放行 |
| `waiting_transfer_detail` | 待付款 + 订单详情标题 | 点击左上角返回订单列表 | 返回列表 | 确认到账、放行 |
| `unknown` | 未匹配其他页面 | 等待；达到刷新阈值后刷新 | 识别到已知页面 | 连续坐标点击 |

## 模态框

| 模态框标识 | 操作 | 说明 |
|---|---|---|
| `trade_notification` | 识别并点击安全的同意接单按钮 | 自动接单，不发送 PushPlus |
| `order_exception_dialog` | 点击“忽略” | 不打开详情、不发送 PushPlus |
| `cancel_confirm_dialog` | 在超时取消流程中点击确认 | 仅对已验证目标执行 |
| `password_dialog` | 读取控制台内存密码或环境变量后输入 | 密码不写配置、不记日志 |

## 代码归属

| 目录 | 责任 |
|---|---|
| `canvas_bot/core/` | 页面上下文、通用数据类型、文本与路径工具 |
| `canvas_bot/browser/` | Playwright 与 Flutter 输入能力（当前下一步继续迁移） |
| `canvas_bot/vision/` | OCR、模板与页面识别能力（当前下一步继续迁移） |
| `canvas_bot/pages/` | 普通页面的路由与动作 |
| `canvas_bot/dialogs/` | 高优先级弹窗处理 |
| `canvas_bot/workflows/` | 挂单、接单、多挂单、取消重挂等跨页面流程 |
| `canvas_bot/services/` | PushPlus、调试输出等外部服务 |

`CanvasBot` 只负责保存运行状态、提供底层业务动作，并调度以上模块。
