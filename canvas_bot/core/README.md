# `core`：无副作用的公共基础

## 职责

- `context.py`：`PageContext`，封装一次 OCR 扫描对应的浏览器对象、画面、坐标和文本框。
- `models.py`：`Rect`、`TextBox`、`TemplateMatch` 等数据模型。
- `text.py`：路径解析、文本归一化、关键词拆分和基础数值工具。

## 允许

- 使用标准库。
- 定义不可变数据和纯函数。
- 被任意其他模块导入。

## 禁止

- 不得导入 `CanvasBot`、Playwright 页面对象或通知服务。
- 不得点击页面、读写配置、发网络请求、打印业务日志。
- 不得在此处写挂单、接单、取消或支付密码规则。

`PageContext` 的 `image`、`boxes` 必须来自同一轮扫描；处理器不得假定它们会随页面变化自动更新。需要新画面时应返回 tick 主循环重新扫描。
